## 1. Отдельный интерфейс

Готовый исполняемый файл:

`build/HealthcareSanatoriumInterface.exe`

Интерфейс использует Access-БД `HealthcareSanatoriumSystem.accdb`, но приложение и база существуют отдельными файлами. Приложение собрано компилятором C# из .NET Framework 4.x.

### Рабочие окна:
- главное меню;
- пенсионеры (добавление, удаление, поиск, фильтрация);
- журнал путевок (CRUD операции, фильтры, отчеты);
- санатории (просмотр, добавление);
- сервис данных (очистка, диагностика).

### Реализованные функции:
- ✅ Кнопки навигации и вызова рабочих окон
- ✅ Кнопки предпросмотра и печати отчетов Access
- ✅ Текстовые поля поиска с debouncing
- ✅ Выпадающие списки фильтров с кешированием
- ✅ Флажки фильтрации
- ✅ CRUD операции (добавление, удаление, редактирование)
- ✅ PDF экспорт с асинхронностью (не блокирует UI)
- ✅ Профессиональные toast-уведомления
- ✅ Обработка всех ошибок с логированием
- ✅ Retry logic для нестабильных соединений с БД
- ✅ Glassmorphism интерфейс с двумя темами

### Стиль интерфейса:
- Современный glassmorphism с мягкими градиентами
- Стеклянные панели с полупрозрачностью
- Кастомные скругленные кнопки
- Hover/press-состояния с плавными переходами
- Оптимизирован для 4K/HiDPI мониторов

### Темы:
- ✅ Светлая тема
- ✅ Темная тема (нажимается на главной форме)
- ✅ Плавное переключение без зависаний

## 2. Установочный пакет

Готовый установщик:

`dist/Setup.exe`

Установщик:
- предлагает директорию по умолчанию;
- позволяет выбрать другую папку;
- устанавливает приложение, Access-БД и руководство;
- проверяет наличие .NET Framework 4.x;
- содержит кнопку открытия компонентов Windows для доустановки .NET-компонентов;
- создает ярлык на рабочем столе и/или в меню Пуск;
- содержит руководство пользователя `UserGuide.txt`;
- может запустить приложение после установки;
- показывает подробный статус каждой операции;
- обрабатывает ошибки и показывает информативные сообщения.

`Setup.exe` самодостаточный: приложение, база и руководство встроены внутрь установщика как ресурсы.
